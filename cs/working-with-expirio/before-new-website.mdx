Nový web se málokdy zadrhne kvůli samotnému designu. Problémy obvykle vznikají z rozhodnutí, která zůstala na začátku nedořešená.

Tady je pět věcí, které stojí za to vyjasnit ještě před zahájením práce. Teď se řeší snadno a po zahájení vývoje se mění výrazně hůř.

## 1. Ujasněte si, proč web předěláváte

„Vypadá zastarale" může být pravda, ale jako cíl projektu to nestačí.

Vizuální redesign může web udělat současnějším. Nemusí ale zlepšit to, jak dobře podporuje byznys.

Rozhodněte, co se má díky projektu změnit. Může to znamenat:

- relevantnější poptávky,
- kratší obchodní proces,
- méně opakujících se dotazů na podporu,
- kvalitnější uchazeče o práci,
- srozumitelnější komunikaci vašich služeb.

Odpověď ovlivní strukturu webu, jeho obsah i způsob, jakým se po spuštění bude měřit jeho výkon.

<Warning>
  Pokud nepanuje shoda na tom, co má web zlepšit, neexistuje jasná definice úspěchu. Pozdější rozhodnutí se pak spíš řídí osobními preferencemi.
</Warning>

## 2. Určete, kdo má finální slovo

Jednou z nejčastějších příčin zdržení je nejasnost v tom, kdo může udělat konečné rozhodnutí.

Práci může připomínkovat víc lidí a často je to užitečné. Jeden člověk by ale měl být odpovědný za to, že vyřeší rozporuplné připomínky a schválí směr za celý tým.

Bez jasně určeného člověka trvají kola připomínek déle a projekt se může zastavit, zatímco všichni čekají na interní shodu.

## 3. Začněte připravovat obsah včas

Obsah zabere obvykle víc času, než se čeká.

Psaní textů, výběr fotografií, kontrola informací o produktech a schvalování právních formulací mohou odhalit otázky, které dosud nikdo neřešil. Pro koho ta služba doopravdy je? Které přínosy jsou nejdůležitější? Popisuje se nabídka napříč firmou konzistentně?

Pokud to jde, začněte tyhle podklady připravovat ještě před fází návrhu. I rozpracované verze jsou užitečné.

Návrh nad skutečným obsahem nám umožní lépe rozhodovat o délce stránek, hierarchii a rozvržení. Výplňový obsah nám neukáže, že skutečný titulek je delší, že dostupné fotografie mají jiný formát nebo že seznam produktů obsahuje 47 položek místo tří.

## 4. Ověřte si, k čemu máte přístup

Než začnete web předělávat, zjistěte, kdo spravuje systémy, které s ním souvisejí.

Může jít o:

- registrátora domény,
- hostingový účet,
- analytický účet,
- stávající web a jeho zdrojové soubory,
- služby pro formuláře a e-maily,
- nástroje pro správu cookies,
- další integrace, které web využívá.

Tyhle detaily se stanou důležitými při spuštění. Chybějící přihlášení k doméně dokáže zdržet publikaci i ve chvíli, kdy je nový web jinak hotový.

Přístupy jsou obzvlášť důležité, pokud stávající web spravuje jiná agentura nebo dodavatel. Pokud si nejste jistí, co vaše firma vlastní a kdo drží jednotlivé účty, vyřešte to včas. Náš [bezpečnostní checklist](/cs/topics/security) podrobněji vysvětluje, co ověřit.

## 5. Rozhodněte, kdo se o web bude starat

Web bude po spuštění potřebovat pozornost.

Obsah zastarává. Služby se mění. Přibývají nové případové studie. Analytika může ukázat, že si některé stránky vedou líp než jiné. Technické aktualizace a bezpečnostní požadavky pokračují také.

Rozhodněte, kdo bude za web odpovědný, jakmile bude venku. Vyjasněte si, jestli ta odpovědnost zahrnuje:

- publikování a aktualizaci obsahu,
- technickou údržbu,
- sledování formulářů a integrací,
- vyhodnocování analytiky,
- postupné vylepšování webu.

Může to zajišťovat interní tým, externí partner nebo kombinace obojího. Podstatné je, aby byla odpovědnost jasná.
